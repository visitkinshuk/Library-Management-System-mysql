Library Management System using MySQL

Project Overview

This project is a relational database-based Library Management System developed using MySQL. It is designed to manage key library operations including books, members, employees, branches, book issuance, and book returns.

The project demonstrates practical implementation of database design, SQL querying, data integrity constraints, reporting, and stored procedures.

Stored Procedure

The project includes a stored procedure called issue_book.

The procedure:

Checks whether a requested book is available.

Creates an issue transaction when the book is available.

Updates the book status from yes to no.

Returns a confirmation message after successful issuance.

Returns an unavailable message when the book cannot be issued.

Sample Business Questions Solved

The project answers several practical library-management questions, including:

Which books have not yet been returned?

Which members have issued multiple books?

What is the total rental income generated by each category?

Which members currently have overdue books?

Which employees process the highest number of book issues?

How many books were issued and returned by each branch?

What revenue was generated by each branch?

Which members have recently been active?
